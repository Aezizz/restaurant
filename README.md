#  Vyna Coffee POS & Restaurant Management System

> Sistem Point of Sales (POS) dan manajemen restoran berbasis web modern yang dibangun untuk efisiensi operasional kafe secara *real-time*.

---

##  Fitur Utama

- **Multi-Role Access Control (RBAC):** Pembagian hak akses yang ketat dan aman untuk **Admin**, **Kasir**, dan **Pelanggan** (Customer).
- **Manajemen Menu & Stok Real-Time:** Kelola kategori, harga, deskripsi, dan pembaruan stok produk secara instan langsung dari panel kontrol admin.
- **Antarmuka Responsif (Mobile-Friendly):** Dioptimalkan untuk diakses melalui perangkat mobile maupun desktop oleh pelanggan dan staf.
- **Kitchen Display System (KDS):** Integrasi WebSocket untuk menampilkan pesanan masuk secara *real-time* langsung ke bagian dapur.
- **Pemesanan Mandiri & On-The-Spot Kasir:** Mendukung alur pemesanan mandiri oleh pelanggan melalui web maupun pencatatan pesanan langsung oleh kasir.
- **Keamanan Terjamin:** Enkripsi *password* menggunakan `bcrypt` dan sistem manajemen sesi berbasis token.

---

## Tech Stack

**Frontend:**
- React.js / Vite
- Tailwind CSS
- Lucide Icons
- React Toastify / React Router DOM

**Backend:**
- Node.js & Express.js
- MongoDB & Mongoose (Database)
- Socket.io (Real-time WebSocket)
- JWT & bcrypt (Authentication & Security)
